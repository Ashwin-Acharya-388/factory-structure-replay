# Factory Structure Replay

Static website: a year-by-year replay of workforce-structure advice for Indian factories, grouped by state,
built from the Annual Survey of Industries (ASI) 2016-17 to 2024-25 (MoSPI).

Each year's advice comes from a model trained only on earlier years. The site shows group-level aggregates only
(per state and year: number of sample factories, shape shares, median real value added per person, share advised
to move). No factory-level data and no source code are included. Results are associations, not causal effects.
